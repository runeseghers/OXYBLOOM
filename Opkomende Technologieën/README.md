## Onderwerp
Als onderwerp hebben we gekozen voor Oéxybloom het project voor Gebruiksgericht Ontwerp. Oxybloom is een bloem die de aan de hand van licht, beweging en geluid de gebruiker verteld wat de status van de luchtkwaliteit in het huis is.
